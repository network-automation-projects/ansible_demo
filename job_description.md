Target Role: Backend Engineer – AI Systems & Automation
Location: Remote / Hybrid
Type: Full-Time
About the Role
We are seeking a Backend Engineer to design and build AI-powered application systems that integrate large language models (LLMs) into production workflows. This role focuses on building scalable APIs, orchestrating AI-driven processes, and ensuring reliability, observability, and cost control in AI-enabled services.
You will not be training new models. Instead, you will design systems that use existing AI services effectively and responsibly.
What You Will Do
Design and implement Python-based backend services using FastAPI or similar frameworks
Integrate external AI APIs (LLMs, embeddings, speech-to-text, etc.) into production systems
Build document ingestion pipelines (chunking, embedding, indexing, retrieval)
Implement Retrieval-Augmented Generation (RAG) workflows
Design asynchronous job processing systems (background workers, task queues)
Add retry logic, rate limiting, caching, and error handling to AI calls
Implement structured logging, metrics, and monitoring for AI services
Manage API keys and secrets securely
Optimize performance and cost of AI inference workflows
Write unit and integration tests
Participate in system design discussions focused on reliability and scale
Technical Requirements
Strong proficiency in Python
Experience building REST APIs (FastAPI, Flask, or similar)
Experience with asynchronous programming (async/await)
Familiarity with external API integration
Experience with PostgreSQL or NoSQL databases
Understanding of background task processing (Celery, RQ, asyncio workers, etc.)
Familiarity with Docker and CI/CD pipelines
Experience implementing retry/backoff and resilience patterns
Nice to Have
Experience building RAG systems
Familiarity with vector databases (pgvector, Pinecone, Weaviate, etc.)
Experience deploying services to AWS/GCP/Azure
Experience with caching systems (Redis)
Experience monitoring APIs with Prometheus/Grafana
Understanding of cost optimization for API-based AI systems
What Success Looks Like
AI features are deployed safely and reliably
Latency and cost are monitored and controlled
Workflows are automated end-to-end
Systems degrade gracefully when AI services fail
Developers and stakeholders can trust the system
