# Drill 0: Write a Function

Super simple warm-up. Write a function with a docstring and type hints.

## Requirements

- Write a function `add(a, b)` that returns the sum of two numbers
- Add a docstring
- Add type hints for parameters and return value

## Example

```python
>>> add(2, 3)
5
>>> add(-1, 1)
0
```
